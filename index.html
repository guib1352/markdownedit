내 빠른 문자 관리

자주 쓰는 문자나 문구를 등록해 두면 상단 버튼을 누르는 즉시 커서 위치에 입력됩니다.

비워 두면 입력할 내용을 버튼에 표시합니다.
등록한 문자 0개

↑ ↓ 버튼으로 표시 순서를 바꿀 수 있습니다. 문자·버튼 이름·순서가 현재 브라우저에 즉시 저장됩니다.

노션에 저장하면 다른 기기에서도 같은 빠른 문자 목록을 쓸 수 있어요.

금지어 감지 관리

크랙에서 오탐할 수 있는 문자열을 등록하세요. 예를 들어 보지를 등록하면 보지않음의 해당 글자만 PREVIEW에 붉게 표시합니다.

입력 방해·자동 치환 없이 확인만 합니다. 투명문자 입력은 기존 빠른 문자를 이용하세요.

등록된 문자열0개

부분 문자열 포함 검사, 대소문자 구분 없음. 등록·삭제 후 이 브라우저에는 즉시 저장되고 하이라이트가 반영됩니다.

노션과 연결하면 모든 기기에서 같은 목록을 쓸 수 있어요.

노션 연결 설정

내 노션 데이터베이스 하나를 프롬프트 보관함으로 사용합니다. API 토큰과 데이터베이스 주소는 이 브라우저에만 저장돼요.

Notion 통합(연동)을 만든 뒤, 대상 데이터베이스에 연결 권한을 부여하세요. GitHub 파일에는 토큰을 직접 적지 않습니다.
노션의 일반 표가 아닌 데이터베이스 표 보기를 연결해야 합니다. 데이터베이스 링크나 '데이터 소스 ID 복사'로 얻은 ID도 사용할 수 있어요.

노션에서 불러오기

데이터베이스의 속성을 그대로 표시합니다.
불러오기 버튼을 누르면 목록이 표시됩니다.

노션에 새 문서 저장
